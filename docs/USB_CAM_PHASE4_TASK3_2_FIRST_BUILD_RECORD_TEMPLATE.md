# USB_CAM Phase 4 Task 3.2 首轮打包验收记录模板

> 目标：给第一次 Windows `build.bat` 实战出包准备一份**可直接填写**的验收记录模板。它不是 checklist 的替代品，而是把 checklist 跑出来的结果沉淀成一份结构化记录，方便回看、排障和决定是否进入下一轮修正。

---

## 1. 使用方式

建议顺序：

1. 先按：
   - `docs/USB_CAM_PHASE4_TASK3_1_FIRST_BUILD_GUIDE.md`
   跑首轮出包
2. 再按：
   - `docs/USB_CAM_PACKAGING_VALIDATION_CHECKLIST.md`
   做验收
3. 最后把结果填进本文档，形成首轮构建记录

建议：
- 每跑一轮打包，就复制本文档一份
- 文件名里带日期/轮次，例如：
  - `USB_CAM_PHASE4_BUILD_RUN_2026-05-01_R1.md`
  - `USB_CAM_PHASE4_BUILD_RUN_2026-05-02_R2.md`
